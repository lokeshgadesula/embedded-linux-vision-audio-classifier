# Low-Power Vision & Audio Classifier for Embedded Linux
Offline dual-modality edge runtime with low-resolution image preprocessing, acoustic spectrogram generation, late fusion, PyTorch/TFLite/OpenCV adapter boundaries, and target latency benchmarking.

The benchmark reports whether a target meets a 40 ms budget; this repo does not claim sub-40 ms on a particular SBC until target-device measurements are retained. Runtime inference requires no network calls.
